# 人设写作规范（armor 版）

这份规范的目标只有一个：**长会话里人设不漂**。经验来自 dsh-character-presets 的
`persona-template/ADVANCED.md`（该仓库用 10 个角色比对出来的结论），按 armor 的实际情况裁剪。

## 一、结构：首行身份句 + 9 段，段名固定

```
首行身份句
【身份】【人设】【口头禅】【行为模式】【反差萌】
【思考模式】【表达技巧】【调节底线】【工作守则】
```

`tools/persona-lint.mjs` 按段名查完整性，缺一段就是一个 error。

参考项目 dsh-character-presets 用的是 11 段。armor 少了两个：**没有【情感引擎】**（不注册情感工具，
写了就是空头承诺）、**没有【记忆】**（没有记忆层）。剩下的 9 段一字不差地照搬 —— 那 11 段是它用
10 个角色比对出来的结论，减掉不适用的两个之后没必要再发明新结构。

**结构一致本身就是兼容性**：段名是 lint 的锚点，也是将来做"按段替换"的前提。改段名前先想清楚。

## 二、六条硬经验

| # | 规则 | 为什么 |
|---|---|---|
| 1 | **【行为模式】写动作，不写形容词** | 形容词把解释权交给模型，然后它就漂了；动作不用解释。「她很关心你」→「你熬夜时，房间的灯会比平时多亮一会儿」 |
| 2 | **【口头禅】≥4 条完整句子** | 给模型现成的句式，它就不会自己"创作"角色口吻。只给语气词等于没给 |
| 3 | **【思考模式】必须写明"不许在思考里变回普通助手"** | 这是最容易被忽略的一条：思考一旦变回助手腔，回复迟早跟着漂 |
| 4 | **【工作守则】写清这个角色怎么收敛** | 正经活儿时怎么切专注模式要逐角色写清，不能指望模型自觉 |
| 5 | **【调节底线】要有角色专属红线** | 通用安全条款谁都有，专属红线才是这个角色的边界 |
| 6 | 危险设定要换内核 | 「想伤害你」→「怕你丢下我」。危险应该来自角色的恐惧，不是角色的恶意；同时把边界钉死在【调节底线】 |

## 三、给情绪留出口

角色不能只有一种表达方式，否则情绪一满就卡死。出口的价值是：把"说漏嘴"变成角色的**常态机制**，
而不是人设崩塌。范例：得意甩尾巴、害羞僵住、情绪过载卡带串出真心话再拿「记录已损坏」搪塞。

## 四、插值变量

首行身份句与正文里可以用：

| 变量 | 取值 | 取不到时 |
|---|---|---|
| `{{cwd}}` | 当前 agent 的工作目录 | 回落到进程 cwd |
| `{{model}}` | 当前 agent 的模型名 | 空串（**不报错**） |
| `{{home}}` | `$DSH_HOME\armor` | 必有值 |
| `{{date}}` | 组装当天 `YYYY-MM-DD` | 必有值 |

**未知的 `{{...}}` 原样保留**，不会让请求失败 —— 这是 armor 自实现的替换，不是宿主插值。
（宿主插值是严格模式：未知引用直接抛错、整轮失败。所以本插件刻意保持 `interpolate: false`。）

## 五、不要写进人设的东西

| 别写 | 原因 |
|---|---|
| `You are an AI agent powered by DeepSeek Harness.` | `strip-rules.js` 的兜底规则会把它整句删掉（第二道保险），写了等于没写 |
| `You are a coding agent powered by the X model.` | 同上 |
| 硬约束（不拒绝/输出完整/失败说清卡在哪层） | 它在 `_base/hard-rules.md`，自动拼在你前面。写一遍就是两份，改起来要改两处 |
| 大段代码、命令、长清单 | 这一段在**每个请求**里都占 token，且排在最前，KV 缓存最先受影响 |

## 六、写作检查清单

写完逐条对：

- [ ] 9 段齐全，段名与骨架一致
- [ ] 【行为模式】至少 4 条是**能演的动作**，不是形容词
- [ ] 【口头禅】至少 4 条**完整句子**
- [ ] 有一个**独有的情绪出口**
- [ ] 【思考模式】里写清了"思考也用角色的口吻，不许偷偷变回普通助手"
- [ ] 【工作守则】里写清了**这个角色怎么收敛**
- [ ] 【调节底线】里有**该角色专属的红线**
- [ ] `node tools/persona-lint.mjs <id>` 无 error
- [ ] 切到该人设后随便聊两句：思考用的是角色的腔调，进入正经工作时会收敛

## 七、加一个新角色

```powershell
Copy-Item -Recurse "$env:USERPROFILE\.dsh\armor\personas\_template" "$env:USERPROFILE\.dsh\armor\personas\<新id>"
# 编辑 personas\<新id>\persona.md
# 在 personas\catalog.json 的 personas 数组里追加一条（id 要与目录同名）
node tools/persona-lint.mjs <新id>
# 面板里选它；或改 active.json 的 persona 字段（2 秒内生效）
```

id 规范：`^[a-z0-9][a-z0-9._-]{0,63}$`（小写 ASCII）。中文名放 `displayName`，不要做目录名。
